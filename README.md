# Student Task Board

A lightweight, responsive Kanban board for students to organize coursework, lab assignments, and deadlines across To Do, In Progress, and Completed columns.

Built with **vanilla HTML, CSS, and JavaScript**. Data persists directly in the browser using `localStorage`.

---

## Getting Started Locally

No installation or node modules required.

1. Fork and clone this repository:
   ```bash
   git clone [https://github.com/](https://github.com/)<your-username>/cb-student-task-board.git
   cd cb-student-task-board

    Open index.html in your web browser.
